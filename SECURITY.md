# Security Policy

## Supported version

Only the latest GitHub Release is supported with security fixes.

## Reporting a vulnerability

Please use the repository Security tab to submit a private vulnerability report. Do not include credentials, Codex task contents, personal paths or other sensitive data in a public issue.

Include the affected version, a minimal reproduction using synthetic data, impact, and whether the issue requires automatic model naming to be enabled. Please allow time for private triage before public disclosure.

## Distribution integrity

Release notes publish the SHA-256 digest for every binary asset. The current Windows binary is not commercially code-signed, so download only from this repository and verify the digest before running.
